# Local Video Player 🎥

A feature-rich local video player built with Electron, designed to enhance your video watching experience.

## Key Features 🌟

- **Smart Video Position Memory**: Automatically resumes videos from where you left off
- **Auto-subtitle Positioning**: Automatically restores subtitle positions for each video
- **NVIDIA Video Enhancement**: Supports NVIDIA Video Enhancement for better video quality
- **Recent Videos Playlist**: Maintains a list of recently watched videos for quick access

## Installation 💿

1. Download the latest release from the releases page
2. Install and run the application
3. Start enjoying your videos with enhanced features!

## Usage 🎮

1. Open the application
2. Select your video file
3. The player will automatically:
   - Resume from your last watching position
   - Load and position subtitles correctly
   - Apply NVIDIA enhancements if available
